HOW THE PLATFORM WORKS

System Architecture

A modular architecture for brand risk monitoring, authorized URL reputation checks, and human review.

Input Layer Manual profile and app details
Validation Layer Input validation and normalization
Analysis Engine Name similarity and risk heuristics
Storage Layer SQLite records and review status
Dashboard & Reports Review, summarize and export

Technology stack

  • Python and Flask — backend and routing
  • SQLite — local data storage
  • RapidFuzz — text similarity calculations
  • HTML, CSS, Bootstrap and JavaScript — user interface
  • Groq API — optional assistant responses
  • Browser speech APIs — optional voice interaction

Current limitations

  • External platform monitoring is not active.
  • Risk scores use heuristics, not a trained fraud classifier.
  • Logo pixel comparison is a basic similarity method.
  • Official status requires trusted, manually approved records.
  • Human review is needed before taking action.
